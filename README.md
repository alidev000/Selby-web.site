🏡 Selby | Real Estate Website

A modern and elegant real estate website designed to showcase luxury properties with a clean, minimalist, and sophisticated user interface.

✨ Features

- Modern UI Design: Clean and minimalist visual style.
- Featured Property: Showcases a premium property with images, details, and pricing.
- Property Listings: Displays properties with images, locations, prices, and specifications.
- About Section: Introduces the company's approach and services.
- Statistics Section: Highlights business achievements and key metrics.
- Client Testimonials: Displays customer reviews and experiences.
- Call to Action: Provides easy access to property viewing requests.
- Contact Section: Includes contact information and useful links.
- Footer: Organized navigation and company information.

🛠️ Technologies Used

- HTML5
- CSS3

🎯 Project Goal

This project was created to practice front-end web development, improve HTML and CSS skills, and build a modern real estate website with an elegant user interface.
